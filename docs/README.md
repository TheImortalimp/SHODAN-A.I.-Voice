# SHODAN Voice Interface documentation

These guides describe version 0.0.1 of the SHODAN Voice Interface: the web app at <https://www.imortalimp.nl/006/shodan/shodan.html> and the Windows desktop app.

| Guide | What it covers |
| --- | --- |
| [User guide](./user-guide.md) | Every control on the terminal, keyboard shortcuts, the floating window, and troubleshooting. |
| [AI handle and CORTEX](./ai-handle.md) | How SHODAN writes her own lines, converses, reacts and interjects; connecting a local LLM; scripting her with `window.SHODAN`. |
| [Configuration](./configuration.md) | `shodan.json` defaults, the `monologues.xml` archive, URL parameters, and what the browser stores. |
| [WHITE ICE security](./white-ice.md) | How the web page and the desktop app are hardened, and the limits of that protection. |
| [Desktop app](./desktop.md) | Installing, running, verifying and troubleshooting the WebView2 app for Windows. |
| [Deploying the website](./deployment.md) | Hosting the web build on your own server with the right MIME types and headers. |
| [Development](./development.md) | Building from source, the architecture, the tests, and the release process. |
